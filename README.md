## Featured project

### [Security Findings Agent](https://github.com/oryaffe/SecurityFindingsAgent)

An agentic AI application for vulnerability and exposure workflows, available through a browser chat and CLI.

- Retrieves sample security policies through local RAG.
- Uses MCP tools to access asset findings, patch history, risk acceptances, and remediation tickets.
- Combines authenticated, ownership-scoped data access with conversation context and deterministic checks for selected response claims.
- Runs locally and has been deployed on AWS EC2.

The project demonstrates how I connect cybersecurity workflows with AI application development. It uses synthetic data and sample policies.

**Python · RAG · MCP · Anthropic API · FastAPI · WebSocket · SQLite · ChromaDB · AWS EC2**
